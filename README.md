# PortSwigger Web Security Academy Labs

A structured collection of notes, methodologies, and solutions for PortSwigger Web Security Academy labs.

## About

This repository documents practical techniques for understanding and testing common web application vulnerabilities in controlled lab environments.

Topics may include:

- Authentication vulnerabilities
- Access control issues
- Cross-site scripting (XSS)
- SQL injection
- Cross-site request forgery (CSRF)
- Server-side request forgery (SSRF)
- Command injection
- File upload vulnerabilities
- Path traversal
- Business logic vulnerabilities
- API security
- Web cache poisoning

## Methodology

Each lab or topic should ideally include:

1. Vulnerability category
2. Lab objective
3. Initial observations
4. Testing approach
5. Exploitation steps
6. Root cause
7. Recommended mitigation
8. References



## Disclaimer

This repository is intended for educational purposes and authorized security testing only. Do not use these techniques against systems without explicit permission.
